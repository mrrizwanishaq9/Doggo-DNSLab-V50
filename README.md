# Doggo-DNSLab-V50
Doggo DNSLab V50 is a powerful Python DNS diagnostic toolkit with 50 features including A/AAAA/CNAME/MX/TXT/NS/SOA lookups, UDP/TCP, DoH/DoT, multiple resolvers, DNS health checks, propagation testing, batch scanning, caching, history, JSON/CSV/TXT reports, IDN support, validation, CLI mode, debugging, and an interactive dashboard.
